# Drop real KBCF photos here — no code changes needed

Upload a photo with one of the file names below (`.jpg`, `.jpeg`, `.png`,
`.webp`, or `.avif`) and it automatically replaces the gray placeholder on the
site after the next deploy.

**Easiest way:** on github.com open this folder → **Add file → Upload files** →
drag the photo in → **Commit changes**. Vercel redeploys by itself (~2 min).

| File name          | Where it appears                                      |
| ------------------ | ----------------------------------------------------- |
| `pastors.jpg`      | Home → "Meet Pastors LJ & Karen"                       |
| `pastor-lj.jpg`    | About → Leadership → Dr. LJ Jennings                   |
| `pastor-karen.jpg` | About → Leadership → Dr. Karen Jennings                |
| `dream-center.jpg` | Home Dream Center block + Dream Center page            |

Tips:
- Landscape ~1600×1200 works well for `pastors` / `dream-center`; square
  ~800×800 for the individual pastor portraits.
- Once Sanity (the CMS) is connected, photos uploaded in the Studio take
  precedence over these files — this folder is the zero-setup starter path.
