General
Teacher-Led defaults
Learners — para page & Student-Led (display names stay in local config.json — never committed)

Each learner gets the four enCORE subject buttons on the para page. A Social Skills routine adds one more: log in as the learner in Social Skills, watch that movie the set number of times, then (if ticked) Do the Activity once — an activity already at 100% is skipped, like everywhere else. The display name must match what enCORE and View Students show. The four Student-Led buttons on Home run the first learner. Buttons and the para page show only the pseudonym.

Saving validates first and keeps the previous config as config.json.bak. Invalid input is refused with the reason — nothing broken is ever written.
